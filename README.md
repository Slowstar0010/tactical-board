# Airsoft Tactical Board v2

## 이번 버전에서 수정된 내용

1. 사격 방향
- 첫 클릭 위치가 시작점입니다.
- 마우스/손가락을 움직이면 반투명 미리보기 오버레이가 따라옵니다.
- 두 번째 클릭에서 방향과 길이를 확정합니다.
- 선택 후 회전 핸들로 방향 변경 가능
- 선택 박스의 핸들로 길이/폭 조절 가능

2. 넓은 전술판
- 기존 1200x760 고정판에서 1600x1000으로 확대
- 브라우저 뷰포트보다 큰 캔버스를 스크롤해서 사용
- 향후 완전 무한 캔버스로 확장하기 쉬운 구조

3. 이동 동선
- 첫 클릭: 시작점
- 이동/두 번째 클릭: 방향과 길이 확정
- 선택 후 회전 핸들로 방향 변경
- 크기 핸들로 길이 조절

4. 선택 / 이동 / 크기 조절
- 선택 도구에서 객체를 클릭하면 파란색 조절 박스 표시
- 가운데를 누른 채 드래그하면 이동
- 모서리 4개 핸들을 드래그하면 크기 조절
- 위쪽 회전 핸들을 드래그하면 회전
- Delete/Backspace로 삭제
